## Anumati Sandbox — Test Giving and Cancelling Consent

Developers need a safe place to test how users give and cancel data - use permission under the Digital Personal Data Protection (DPDP) framework. Cancelling should be as easy as agreeing. Use mock roles for the service that manages permission and the organisation that uses data. First check what open tools already exist; their absence is not confirmed.

## Build // What to make (MVP & Architecture)
Build an open test setup with fake consent - management and data - use services. It is not a real regulated consent service.

## Key Point // What to keep in mind & safeguard
Automatically check that cancelling permission is as easy as giving it.
